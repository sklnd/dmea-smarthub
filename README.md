# dmea-smarthub

A Python client library and CLI for fetching data from DMEA's SmartHub co-op portal.

This project is not affiliated with DMEA or SmartHub. I just want access to my data, so I wrote this client. It may work with other SmartHub portals, but has not been tested with them.
